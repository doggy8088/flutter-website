Flutter 1.5.4 版本發佈說明

  1. 保持最新狀態 chevron_right
  2. 發行說明 chevron_right
  3. 1.5.4 版本發佈說明

自 1.2 版本發佈以來，Flutter 團隊持續專注於提升品質與穩定性。隨著 Google I/O 大會的臨近，Flutter 1.5.4 穩定版也帶來了一系列新功能。此外，Apple 對於 iOS SDK 12.1 版本的建置有設下期限，而本次更新已符合此要求。只需拉取 1.5.4 穩定版，重新建置並將您的 Flutter 應用程式上架至 Apple Store，即可滿足 Apple 的規定。

此外，本次版本也修復了 Flutter 1.2 中出現的兩個回歸問題：

  • #28640 NoSuchMethodError: **android.view.MotionEvent.isFromSource 已於 1.3.7 之後的所有版本中關閉並修復
  • #28484 Widget rendering strange since Flutter update:** 此回歸問題已於 1.4.0 修正

最後，若想了解其他修復與新功能的詳細內容，請繼續閱讀下文。

重大變更（Breaking Changes）

#

我們最近的調查顯示，Flutter 開發者傾向於接受重大變更，只要這能改善 Flutter 的 API 與行為。當然，我們仍會謹慎進行重大變更。以下列出本次版本的重大變更，並附上每項變更的完整說明及在 Flutter 程式碼中的處理方式連結。

  • flutter#26261: CupertinoTextField 的 cursorColor 預設值現在會與應用程式主題一致（公告與因應方式）
  • flutter#26026: 使用原始 EditableText 時需手動觸發選擇工具列（公告與因應方式）
  • flutter#23148: 提出修正以統一 Firebase Messaging Plugin 在 Android 與 iOS 上的回應行為（公告與因應方式）
  • flutter#28014: PointerEvent 轉換為 Diagnosticable（公告與因應方式）
  • flutter#20183: CupertinoTextField：將提供的 TextStyle 與 Theme 的 TextStyle 合併（公告與因應方式）
  • flutter#20693: LongPressGestureRecognizer 在長按後移動不再丟棄 up 事件（公告與因應方式）
  • flutter#20693: GestureRecognizerState 列舉新增 'accepted' 值（公告與因應方式）
  • flutter#18314, flutter#22830, flutter#23424: Drag 的 moveBy 呼叫被拆分，且所有帶有拖曳辨識器的元件預設 DragStartBehavior 改為 DragStartBehavior.start（公告與因應方式）
  • flutter#27891: 所有平台上的實體形狀支援複合圖層（公告與因應方式）
  • flutter#19418: AndroidViewController 新增 onPlatformViewCreated（公告與因應方式）
  • flutter#29070: BackdropFilter 會填滿其父層／祖先的裁剪區域（公告與因應方式）
  • flutter#29816: FontWeight.lerp 若參數為 null 則回傳 null（公告與因應方式）
  • flutter#29696: PointerEnterEvent 與 PointerExitEvent 的 fromHoverEvent 改名為 fromMouseEvent（公告與因應方式）
  • flutter#28602: 允許 PointerEnterEvent 與 PointerExitEvent 可從任何 PointerEvent 建立
  • flutter#28953: 在 semantics tree 中包含 platformViewId
  • flutter#27612: 在帶有 strut 的 TextFields 強制行高
  • flutter#30991: 在 Android 上使用字形的完整高度作為游標高度
  • flutter#30414: 移除部分 pointer events 的壓力自訂化
  • engine#8274: [ui] 在 FontWeight.lerp 中加入 null 檢查

嚴重效能與崩潰修正

#

本次版本修復了多項嚴重效能與崩潰問題。

  • flutter#30990: 允許在 profile 模式下進行元件建構分析
  • flutter#30985: 新增 rrect contains microbenchmark
  • flutter#28651: 無法執行操作，因為 FlutterJNI 尚未連接至 native。
